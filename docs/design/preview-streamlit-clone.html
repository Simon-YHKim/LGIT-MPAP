대화형 생산지표 조회

최근 일주일간 FOL 공정 중 CMP 달성률이 가장 낮은 호기 5개 알려줘
검증됨 intent_parser → planner → SQL · 1.2s 
SELECT machine_no, AVG(cmp_rate) AS avg_cmp
FROM mtba.cmp_daily
WHERE process_l1 = 'FOL'
  AND base_date BETWEEN '2026-04-30' AND '2026-05-07'
GROUP BY machine_no
ORDER BY avg_cmp ASC
LIMIT 5;
